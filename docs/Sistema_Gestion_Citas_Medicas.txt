1. Descripción General del Proyecto
El proyecto consiste en el diseño e implementación de un sistema de gestión de citas médicas,
cuyo propósito es facilitar la organización, reserva y administración de citas entre pacientes y
profesionales de la salud dentro de una institución médica.

En muchos centros médicos, el proceso de asignación de citas se realiza de manera manual o
mediante herramientas poco integradas, lo que genera inconvenientes como conflictos de
horarios, duplicación de citas, dificultades para modificar reservas y una gestión ineficiente de
la agenda médica.

Objetivo del sistema
Optimizar la gestión de citas médicas mediante una plataforma digital que mejore la
organización de la agenda médica, reduzca errores en la asignación de horarios y facilite la
interacción entre pacientes, médicos y administradores.

4. Arquitectura Técnica
El sistema implementa una arquitectura web que separa frontend y backend, siguiendo el
patrón de Arquitectura Hexagonal (puertos y adaptadores). Este enfoque permite que la lógica
de negocio permanezca independiente de los componentes externos, facilitando el
mantenimiento y las pruebas.

7. Conclusiones
El diseño conceptual del Sistema de Gestión de Citas Médicas propone una solución integral
que permite digitalizar y centralizar el proceso de agendamiento de citas en instituciones de
salud. La arquitectura hexagonal elegida garantiza que la lógica de negocio permanezca
desacoplada de los componentes externos, facilitando el mantenimiento y la evolución del
sistema.

El modelo de tres actores (Paciente, Médico y Administrador) con permisos diferenciados
permite un control preciso sobre las operaciones del sistema. Los diagramas UML
desarrollados proveen una base sólida para la implementación, cubriendo los aspectos
estructurales (clases y componentes) y dinámicos (secuencias y actividades) del sistema.

La combinación tecnológica propuesta — Astro en el frontend, Django con Django REST
Framework en el backend, y PostgreSQL como motor de base de datos — representa una pila
moderna, robusta y ampliamente adoptada en la industria, que garantiza la escalabilidad y
mantenibilidad del sistema a largo plazo.
